# AI Research & Prototyping Notebooks

This directory contains Jupyter notebooks used for research, prompt testing, and model fine-tuning for FinTrack AI components.

## Planned Notebooks:
1. `01_ocr_invoice_extraction.ipynb`: Evaluation of OCR pipelines (Tesseract / PaddleOCR / Vision LLMs) on government invoices & vouchers.
2. `02_roadmap_parsing.ipynb`: Parsing sanction letters, milestone schedules, and budget allocations.
3. `03_anomaly_detection_experiments.ipynb`: Unsupervised isolation forests and rule-based anomaly detection on public expenditure logs.
